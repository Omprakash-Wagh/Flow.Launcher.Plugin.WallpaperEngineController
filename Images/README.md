# Plugin Icons

Place your custom `.png` icons in this folder. The plugin expects the following filenames:

- `icon.png` - Main plugin icon (shown in Flow Launcher results)
- `pause.png` - Pause wallpapers
- `play.png` - Play / resume wallpapers
- `stop.png` - Stop wallpapers
- `mute.png` - Mute audio
- `unmute.png` - Unmute audio
- `next.png` - Next wallpaper
- `profile.png` - Profiles list / icon
- `playlist.png` - Playlists list / icon
- `recent.png` - Recent wallpapers list / icon
- `icons.png` - Toggle desktop icons
- `browse.png` - Open / browse wallpapers window
- `settings.png` - Open Wallpaper Engine settings
- `quit.png` - Quit Wallpaper Engine
